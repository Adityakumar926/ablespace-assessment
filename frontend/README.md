# AbleSpace Task Management System - Frontend

**Live Deployed Application**: [https://ablespaceassisment.netlify.app/](https://ablespaceassisment.netlify.app/)  
**Tech Stack**: Next.js 14 (App Router) + TypeScript + Tailwind CSS + Lucide React + Multi-Theme Provider  
**Port**: `3000` (`http://localhost:3000`)  

---

## Key Features

1. **Design Fidelity**: Matches the Figma Task Management Dashboard layout with Kanban Board and Table List views.
2. **Multi-Theme Support**: Light, Dark, Emerald, and Purple themes with instant toggle and `localStorage` persistence across page refreshes.
3. **Guest Login**: One-click Guest Educator login creating persistent session tokens.
4. **Task Operations**: Task creation, editing, drag/status progression, priority filtering (`Low`, `Medium`, `High`, `Urgent`), search, due date tracking, and category tags.

---

## Local Setup & Testing

```bash
# Install dependencies
npm install

# Run automated tests
npm test

# Run Next.js development server
npm run dev

# Run production build
npm run build
```
